# AttendanceManagement

A desktop attendance-tracking application built with Java Swing and SQL Server, developed in NetBeans. It has three roles — admin, professor, and student — and uses a daily code system for checking students into class.

## How it works

Each session, the professor generates a one-time code for their course, which gets stored with a timestamp and the subject. The student then picks their subject and enters that code; the app checks it's valid for the current day before recording their attendance. The admin manages student and professor accounts, and can filter by level and specialty.

## Features

- Single login screen with role selection (admin, professor, student)
- Professor dashboard to view enrolled students and generate a daily attendance code per subject
- Student dashboard to submit the code and see a per-subject attendance summary
- Admin dashboard to manage accounts, filtered by level and specialty
- SQL Server backend accessed through JDBC

## Tech stack

- Java 24
- Java Swing (built with the NetBeans GUI editor)
- Microsoft SQL Server
- mssql-jdbc 13.2.1
- Ant (NetBeans project build)

## Database schema

- `etudiant` — student accounts (cin, nom, prenom, niveau, specialite, classe...)
- `prof` — professor accounts (cin, nom, prenom, matiere, niveau, specialite)
- `code` — daily attendance codes generated by professors
- `presence` — attendance records (cin, matiere, date, niveau, specialite)
- `NiveauSpecialite` — reference table of levels and specialties
- `matiere` — subjects

## Setup

1. Install SQL Server and create a database named `Attendance Management`.
2. Set the database credentials as environment variables (never commit them):
   ```bash
   export DB_USER=<your_sql_user>
   export DB_PASSWORD=<your_password>
   # optional, defaults to localhost:1433 / "Attendance Management"
   export DB_URL="jdbc:sqlserver://localhost:1433;databaseName=Attendance Management;encrypt=true;trustServerCertificate=true;"
   ```
   In NetBeans: *Project Properties → Run → VM Options / Environment* (or set them before launching the IDE).
3. Add the mssql-jdbc driver to the project libraries.
4. Open the project in NetBeans and run `Login.java`.
